Rà soát Theme Dark / Light — LMS Portal

Tôi đã phân tích codebase. Đây là bức tranh hiện tại trước khi chúng ta lên kế hoạch.

✅ Những gì đã có sẵn

🔧 Cơ sở hạ tầng
  • next-themes đã được cài & dùng
  • ThemeProvider có sẵn trong components/
  • Phím tắt D để toggle đã được implement
  • attribute="class" → class .dark trên <html>
  • defaultTheme = light, enableSystem = true
🎨 CSS Variables
  • Light mode: đầy đủ HSL tokens ở :root
  • Dark mode: block .dark { } đã có
  • Tailwind v4 + shadcn/ui đã tích hợp
  • Custom variant: dark (&:is(.dark *))

⚠️ Vấn đề cần giải quyết

🔴 Dark mode tokens thiếu
  • Dark block dùng oklch() → không đồng nhất với light (HSL)
  • Thiếu: --primary-muted, --success-*, --warning-*, --info-*, --danger-*
  • Thiếu: --course-violet/green/blue... cho dark
  • Shadows chưa có dark variant
🔴 Hardcoded colors trong CSS
  • .course { background: #fff; } → không đổi ở dark
  • color: hsl(215 18% 38%) hardcoded trong .nav-item
  • hsl(215 16% 45%) trong .nav-subitem
  • Scrollbar thumb hardcoded màu sáng
  • .search input:focus { background: #fff; }
  • .assistant gradient hardcoded light colors
🔴 UI: Thiếu Toggle Button
  • Không có nút toggle Dark/Light trên UI
  • Người dùng không biết phím tắt D
  • Topbar chưa có ThemeToggle component
🔴 Transition & Polish
  • disableTransitionOnChange đang bật → flash khi switch
  • Chưa có smooth color transition
  • Scrollbar chưa đổi màu theo dark mode
